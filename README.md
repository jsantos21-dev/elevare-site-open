# Elevare Dev

Site institucional estático da Elevare Dev.

## Configuração obrigatória antes de receber leads

Edite `index.html` e configure `WHATSAPP_NUMBER` com DDI + DDD + número, somente dígitos (ex.: 5511999999999). O formulário abre o WhatsApp com os dados preenchidos e não armazena informações no servidor.

## Publicação

Pode ser publicado como Static Site no Render usando este repositório, branch `main`, diretório raiz e sem comando de build. Publish directory: `.`.

## Importante

Os preços exibidos são referências comerciais e devem ser confirmados em proposta. Não há painel administrativo nem armazenamento de leads nesta versão inicial. Para isso, conectar backend e banco com autenticação segura antes de anunciar essa funcionalidade.
